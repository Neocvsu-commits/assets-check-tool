# 资产审查助手 v3.1.0

模型提交或导出前，一键检查 + 快速修复 + 报告归档。把团队验收标准变成可复用的检查预设。

## 解决的问题

外包回收的模型到底合不合格？导出前有没有漏掉 N 边面、UV 越界、轴心没归零？团队里每个人的验收标准不一样怎么办？

这个插件把检查项做成可配置的预设，检查结果用矩阵展示——哪个物体的哪一项挂了，一眼看清。FAIL 优先修，WARN 人工复核。最后导出 CSV/JSON 当返修依据或交付归档。

## 核心功能

### 🔍 检查项全覆盖

按业务维度分 5 组，使用「项目资产要求」「资产导出要求」或「全部检查」选择默认组合：

| 分组 | 检查内容 |
| :--- | :--- |
| 材质与贴图 | 空材质槽、贴图丢失 |
| UV 与颜色 | 越界、重叠、UV 数量、顶点色数量、UV0 豁免 |
| 拓扑与几何 | N 边面、非流形、游离几何、重叠顶点、极点、法线、不平整面、零边、交叉边面 |
| 物体与数据 | 缩放未应用、变换未归零、轴心位置、修改器、动画、顶点权重 |
| 命名规范 | 物体/材质/贴图命名前缀规则 |

### 🔧 一键修复 + 定向修复

**一键修复**处理无争议的基础问题：空材质槽、游离几何、重叠点、基础变换。点一下批量修完。

**定向修复**在每列下拉菜单里，只修你选中的那一项：
- 定位越界 UV / 定位重叠 UV
- 纯三角化 N-gon
- 定位反转法线
- 应用缩放 / 应用全部变换

### 📊 结果矩阵

行是物体，列是检查项，结果用色块标记。支持按名称搜索、按列排序、按结果选中对象。每一列有下拉菜单，可以直接定位或修复。

### 💾 预设管理

三个内置预设随安装包提供，不能删除或覆盖：

- **项目资产要求**：材质使用 `MI_`，允许无 `SM_` 前缀的独立部件；默认不检查居中、变换归零、极点及物体/网格同名，不统一限制平铺 UV。
- **资产导出要求**：物体 `SM_`、材质 `M_`、贴图 `T_`；启用 UV、变换、轴心和数据名检查。
- **全部检查**：启用全部现有检查，保留 UV0 和开放边界豁免选项。

预设只定义现有检查组合，不代表已完成整个部门 SOP 的自动验收。PBR 图集可按实际需要开启 UV 检查。

修改内置预设后点击「保存」会要求另存个人名称。个人预设保存在 Blender 用户配置目录的 `assets_check/presets.json`，不再写入插件目录。换电脑时默认预设自动提供，个人预设需通过 JSON 导出/导入迁移。兼容旧版 JSON 导入；历史碰撞检查开关会被忽略。

### 📋 报告输出

主界面提供两个按钮，均输出 CSV 和 JSON：

- **Twin 用模型报告**：保留原有完整检查明细及字段结构，一项检查一行。
- **模型报告（地编）**：按 SOP 附件的提交对接表输出，包含模型名、三角面数、材质数、贴图类型、预计完成时间、实际提交时间、提交方式、动画信息和备注。文件选择器中填写项目及交付信息；未提供的时间不自动编造。

报告使用最近一次检查时的快照。修改模型后需重新检查。每个网格单独一行；同一资产的独立部件不会自动合并统计。面数基于检查时源网格，不代替最终 FBX 验收；L3 还原度、实际尺寸、材质效果仍需人工确认。

可按物体分别设置 `delivery_texture_type`、`delivery_expected_completion`、`delivery_actual_submission`、`delivery_submission_method`、`delivery_remarks` 自定义属性，它们优先于导出时的统一填写内容。

反馈、作者主页及更新状态移至「编辑 → 偏好设置 → 插件 → 资产审查助手」；主界面保留检查、预设与报告。

### 🔗 与资产导出助手联动

资产导出助手可以读取本插件的审查结果，随资产一起导出 Check 报告。如果导出前没跑审查，导出端的审查选项会自动灰置或跳过。

## 快速上手

1. 选中要审查的 MESH 物体
2. 点击顶栏 `检查` 打开审查弹窗
3. 在"自定义检查"里选预设，确认启用的检查项
4. 点 `开始检查`
5. 优先处理 FAIL，再复核 WARN
6. 批量问题用 `一键修复`，单项精修用列菜单
7. 根据接收方选择 `Twin 用模型报告` 或 `模型报告（地编）`

## 典型场景

**外包验收**：加载"外包验收"预设 → 检查 → 修 FAIL → 复核 WARN → 导出 CSV/JSON 当返修清单。

**导出前质检**：选中待导出对象 → 检查 → 用列菜单处理 N 边面、法线、UV、轴心 → 复检通过 → 进资产导出助手统一导出。

**团队标准落地**：负责人配置好预设 → 导出文件发团队 → 每人导入后按同一预设检查 → 审查口径一致。

## FAQ

**Q1：弹窗点外面就消失了？**
弹窗模式就这样。关闭后从顶栏 `检查` 重新打开。

**Q2：一键修复后面数变少了？**
正常。清理游离几何、合并重叠点本质是删数据，顶点/边/面数减少是预期行为。

**Q3：UV 重叠有时不报？**
当前算法有相邻面及 0—1 范围限制，也未按独立纹理集完整区分。对平铺、色卡等用途请按项目调整开关，复杂图集需要人工复核。

**Q4：旧资产批量报命名问题？**
先检查所选命名规范：项目资产使用 `MI_` 材质，资产导出使用 `SM_` / `M_` / `T_`。快速命名修复遵循当前规范。

**Q5：导出助手里审查项是灰色的？**
导出端要求当前选中对象已有有效审查结果，避免导出空报告。先在本插件跑一次检查就行。

**Q6：定位交叉面按钮报错？**
Blender 4.x 的 `mesh.intersect` 参数有变更，插件已按新枚举修正。如果还报错，重载脚本清掉旧缓存。
